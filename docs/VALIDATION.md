# 준비본 검증 결과

- Python unittest 12개 통과.
- 서울/성남 주소 판정, 민영/국민 분양 포함, 임대/유형 제외, 무순위·취소후재공급 코드 처리 확인.
- 다중 페이지 조회, 중복 페이지/불완전 응답/인증 실패 처리 확인.
- 날짜 형식, 역전된 기간 거부, ICS CRLF·75바이트 접기·UTF-8·종료일·안정적 UID·알림 확인.
- 수집 실패 시 이전 calendar.ics가 유지됨을 확인.
- 합성 데이터 2개 공고로 일정 8개 생성. examples/calendar.sample.ics는 실제 청약 일정이 아님.
- 공식 Swagger의 경로와 사용한 필드를 대조함. 키/실제 공고 데이터를 포함하지 않음.

남은 확인: 본인 발급키를 사용하는 API 실응답, GitHub Actions 실행/Pages 배포, Apple Calendar 구독·알림 수신. 이 준비본에서는 수행하지 않았음.
