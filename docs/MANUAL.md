# 청약홈에 없는 공식 공고를 직접 추가하기

LH/SH/GH 공식 모집공고문을 확인한 뒤 `data/manual_notices.json` 배열에 넣습니다. 기본값은 빈 배열 `[]`입니다. 이 파일에는 본인 정보가 아닌 공개 분양 일정만 넣으세요. 공개 저장소에 올라갑니다.

형식 설명용 예시입니다. **아래의 단지명·날짜·ID·URL은 실제 공고가 아니므로 그대로 운영 파일에 넣지 마세요.** URL은 해당 기관의 공식 공고 상세 페이지 주소로 바꿔야 합니다.

```json
[
  {
    "id": "lh-official-announcement-unique-id",
    "name": "공식 공고문의 단지명으로 교체",
    "address": "경기도 성남시 분당구 공식 공급주소로 교체",
    "property_type": "apartment",
    "tenure": "sale",
    "supply": "공공분양",
    "source_url": "https://apply.lh.or.kr/",
    "events": [
      {"kind": "notice", "label": "모집공고", "start": "2026-11-01"},
      {"kind": "special", "label": "특별공급 접수", "start": "2026-11-10", "end": "2026-11-11", "application": true},
      {"kind": "general", "label": "일반공급 접수", "start": "2026-11-12", "end": "2026-11-13", "application": true},
      {"kind": "winner", "label": "당첨자 발표", "start": "2026-11-20"}
    ]
  }
]
```

- 단지별 `id`는 고유하게 정하고 수정해도 유지합니다. 일정의 `kind`도 단지 안에서 고유해야 합니다. 시작일 수정 시 같은 UID로 갱신됩니다.
- 청약홈에도 이미 있는 같은 공고를 수동으로 추가하면 중복될 수 있습니다. 자동/수동 출처 사이에는 추측에 의한 단지명 중복 제거를 하지 않습니다.
- 날짜는 `YYYY-MM-DD`. `end`는 **마지막 접수일 포함**이며 생략하면 하루 일정입니다. 프로그램이 ICS의 배타적 DTEND로 변환합니다.
- `application: true`인 일정만 3일 전/1일 전 알림을 넣습니다.
- `property_type`은 `apartment`, `tenure`는 `sale`만 허용합니다. 이 표시는 사용자가 원문에서 확인한 사실이어야 합니다. 임대라는 단어가 없는지만 보고 분양이라고 판단하지 마세요.
- 공고 변경 시 같은 ID의 내용을 수정하고, 취소 시 해당 항목을 삭제한 뒤 Actions를 수동 실행합니다.
- 원문 확인 전 날짜를 추정해 넣지 않습니다. 모르는 일정은 생략합니다. 거주요건/소득요건 등 신청 자격을 자동 판정하지 않습니다.
